# Document Planning

Plan an important document before drafting it. The goal is agreement about the outcome, reader, evidence, and structure—not premature prose.

## Process

Work through these questions with the user:

1. **Document type:** What is being written, and what decision or action surrounds it?
2. **Terminal goal:** What should be different after the intended reader reads it?
3. **Audience:** Who exactly will read it? What do they know, value, fear, and control?
4. **Evidence:** Which claims require support, and what sources are authoritative for each?
5. **Failure:** What reader response would show that the document failed?
6. **Constraints:** Length, tone, format, deadline, review process, and required sections.
7. **Structure:** What sequence gives the reader the context needed for each conclusion?

Ask one consequential question at a time when the answer changes later choices. Restate the answer before proceeding if ambiguity remains.

## Output

```markdown
# Document Plan: [Working Title]

## Intended Outcome
## Audience and Context
## Required Evidence
## Failure Conditions
## Constraints
## Proposed Structure
## Open Questions
```

Each proposed section should state what job it performs for the reader. Do not draft the full document unless requested.
