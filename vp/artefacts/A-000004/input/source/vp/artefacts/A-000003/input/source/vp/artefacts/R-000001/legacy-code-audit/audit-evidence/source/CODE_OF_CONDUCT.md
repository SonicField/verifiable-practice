# Code of Conduct

## Our Pledge

We commit to making participation in Verifiable Practice respectful and free from harassment for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity or expression, experience, education, socio-economic status, nationality, appearance, race, caste, colour, religion, or sexual identity and orientation.

We commit to acting and interacting in ways that support an open, welcoming, diverse, inclusive, and healthy community.

## Expected Behaviour

Examples include:

- showing empathy and respect for different experiences and viewpoints;
- giving and accepting constructive, evidence-based feedback;
- acknowledging mistakes and learning from them;
- focusing criticism on ideas and work rather than people;
- respecting privacy, consent, and attribution.

## Unacceptable Behaviour

Examples include:

- harassment, intimidation, trolling, or discriminatory language;
- personal or political attacks unrelated to the work;
- unwanted sexual attention or advances;
- publishing private information without explicit permission;
- conduct that a reasonable person would consider inappropriate in a professional community.

## Scope

This code applies in repository spaces and when someone officially represents the project in public spaces.

## Enforcement

Report unacceptable behaviour privately to the project maintainers using a contact method listed on the repository owner's profile. Maintainers will respect the reporter's privacy, investigate fairly, and take action proportionate to the circumstances. Do not open a public issue containing sensitive personal information.

Project maintainers may remove, edit, or reject contributions and may temporarily or permanently restrict participation when behaviour violates this code.
