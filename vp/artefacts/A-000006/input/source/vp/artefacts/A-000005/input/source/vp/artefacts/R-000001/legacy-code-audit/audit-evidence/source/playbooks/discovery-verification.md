# Discovery Verification

Verify a discovery report before using it as the sole input to recovery. This is a completeness check, not a second discovery.

## Checks

Confirm that the report contains:

- a one-sentence terminal goal confirmed by the user;
- every searched location plus explicit exclusions;
- an artefact triage table with evidence and rationale;
- valuable outcomes and how they were verified;
- ordered instrumental goals with dependencies;
- full confirmed restatements from gap analysis;
- open questions, uncertainty, and recommended next steps.

Compare the report against available conversation and source evidence. Look specifically for:

- user context compressed into a misleading summary;
- decisions mentioned in conversation but absent from the report;
- technical claims with no pointer to supporting evidence;
- inferred verdicts presented as user-confirmed facts;
- relevant locations that were never searched;
- recommendations that do not follow from the recorded goals.

## Output

Report each required section as complete, incomplete, or missing. List exact corrections. End with one status:

- **Ready for recovery**
- **Ready after listed corrections**
- **Not ready; discovery must resume**

Do not repair source artefacts during verification. Amend the report only if the user requested that change.
